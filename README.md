# NovaMart Sales Analytics Dashboard

## Project Overview
NovaMart Sales Analytics is an interactive Power BI project developed to analyze sales, profit, customer behaviour, product performance, store performance, and regional trends.

The project uses Power BI, Power Query, and DAX to transform business data into interactive dashboards and actionable insights.

## Objectives
- Analyse sales and profit performance
- Identify top products and brands
- Monitor store and employee performance
- Track sales against targets
- Generate AI-powered business insights

## Dataset
- Dataset: Custom NovaMart Sales Dataset
- Records: ~2,000 Orders
- Period: FY 2024 – FY 2026
- Domain: Retail Sales Analytics

## Tools & Technologies
- Power BI
- Power Query
- DAX

## Data Model
The project uses a Star Schema data model with fact and dimension tables.

### Key Tables
- Fact_Order
- Fact_Return
- Fact_Sales_Target
- Dim_Product
- Dim_Customer
- Dim_Store
- Dim_Employee
- Dim_Shipping
- Dim_Calendar

## Key Business Insights
- December achieved the highest monthly sales.
- Apple generated the highest brand sales.
- Footwear contributed the highest category revenue.
- North Region led in total orders.
- NovaMart Store 21 recorded the highest sales performance.
- Jyoti Padmanabhan achieved the highest sales among employees.
- Defective products accounted for the highest number of returns.
- Net Banking was the most preferred payment method.

## AI-Powered Analytics
AI features were used to summarize dashboard insights, identify sales drivers, highlight business patterns, and support faster decision-making.

The project uses Power BI Smart Narrative and Key Influencers for AI-powered analysis.
